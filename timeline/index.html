How to read this

A demo's card sits at the year it was written. Its bar in the chart runs from the first SGI channel that carried it (a demo tape, an IRIX release, a Developer Toolbox) to the last one the project has evidence for; a lighter bar means the end is an inference. Dates come from file timestamps on the archived tapes, author lines in the source, comp.sys.sgi posts, SGI's release notes, and IRIS Universe; each card lists its sources. Where a date is inferred the note says so.

The IRIX release contents will firm up as the project reads each release's package listings; the last release to carry each demo is the least certain column here.

Machine photographs are from Wikimedia Commons under the licences listed in credits.md; hover a picture for its credit. Data and page: sgi-demos.github.io/timeline. Thumbnails and the demos themselves: sgi-demos.
